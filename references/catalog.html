非关系页不走关系→结构→组件流程,
在页面规划期就排进页序,生产时直接套 paper-ink 画册模板:换文字,不换版式与固定件。
这页是浏览入口,不是正式分类。
借 SmartArt「先问要表达什么」的九个语义入口逛 67 张关系页版式,每类入口的定义见各组标题;字母编号只是源画册历史分组,不代表六大族/六种结构(G3 为退役空位,不重编),判定看每张卡的 23 细种关系标签(词表见 SKILL.md 表A),不以这里的入口为准。
结构 = 版心怎么切(矩形分块);组件 = 区域内画什么形状。
页眉、页码、题注等固定件不算切分;放射、环形、漏斗、表格这些形状是组件画法,不影响结构归属。关系先圈定候选结构(2~4 种),再按对象数量、有无辅助内容、方向偏好在范围内选定。每类结构 = 空槽蓝图 + 对应真实版式成对展示;67 个版式全部归入这 6 种切分,不漏归、不重归、不跨结构。
组件 = 参数化画法:内容数量是参数,画法不同才是不同组件。
atlas / native / ECharts 按与版式相同的 SmartArt 语义入口分组;每个组件只放最主要的表达类型,不在多个入口重复出现。ECharts 类保留 Apache ECharts 6.1.0 官方来源与 Apache-2.0 许可署名。卡片统一用 catalog #001–#079 连续编号,源组件编号只做内部路由。semantic./media. 前缀的流式机器组件不进浏览池,按 component_id 查 capabilities/components/routing-manifest.json。
