整页级模板,含版式与视觉
这里借用 SmartArt 的“先问要表达什么”来分类。列表 = 无顺序并列;流程 = 步骤/时间/方向;循环 = 持续重复;层级 = 上下级;关系 = 非方向连接/对照;矩阵 = 二维分类或部分与整体;金字塔 = 比例收窄;图片 = 图片/原文主导。Wise PPT 另补“数据”,收纳图表、指标、排名和地图。分类只负责浏览,卡片下方仍保留项目的六大族关系标签。
结构 = 页面区域怎么切(矩形分块);组件 = 区域内画什么形状。结构切的是版心:每页固定的左上页眉 / 左下页码 / 底部题注行是外框,一律不算切分;单区 = 版心剩一整块,内容水平垂直居中。放射、环形、蛇形、漏斗、矩阵(表格)都是区域内组件的画法,不是页面结构。关系圈定候选结构(2~4 种),二次判断(对象数量 / 有无辅助内容 / 方向偏好)在范围内选定。关系页版式全部归入这 6 种切分。
网格 vs 表格(易混):网格 = 页面切分,均质等价陈列(A7 logo 墙、F4 六宫格);表格/矩阵 = 组件画法,行列双语义在组件内部 —— K4 = 左右3等分(三栏切分,行带是栏内画法)、E4/K1 = 上下不对称(矩阵 + 收束带)。页面切分只认 6 种矩形分块,不设「表格」。
组件 = 参数化画法。内容数量是参数不是组件类型;画法不同才是不同组件。atlas + native + ECharts 按与版式相同的 SmartArt 语义入口分组;每个组件只放入最主要的表达类型,避免一件多处重复。“数据”是 Wise PPT 对 SmartArt 的扩展,不是新的关系族。
