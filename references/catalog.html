关系页走 定关系 → 圈候选结构 → 二次判断 → 选组件。同一关系可落到多种结构;结构只负责切区域,区域内由组件负责。
结构 = 页面区域怎么切(矩形分块);组件 = 区域内画什么形状。放射、环形、蛇形、漏斗都是区域内组件的画法,不是页面结构。关系圈定候选结构(2~4 种),二次判断(对象数量 / 有无辅助内容 / 方向偏好)在范围内选定。关系页版式全部归入这 7 种切分,版式编号可点击跳到「关系页版式」tab 对应卡片。
网格 vs 表格(易混):网格均质等价,格与格只是陈列(A7 logo 墙、F4 六宫格);表格行有行语义、列有列语义,交叉格才有内容(K4 场景×阶段、E4 前后×环节)。E4 的「上下2等分 + 底带」按行列双语义计入表格。
组件 = 参数化画法。内容数量是参数不是组件类型;画法不同才是不同组件。atlas + native + ECharts 全部组件,按信息关系六大族统一分组(重心族无独立组件,由非关系页模板承担)。
